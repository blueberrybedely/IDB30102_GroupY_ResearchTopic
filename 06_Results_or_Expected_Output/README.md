# Results / Expected Output

This folder contains the expected output and evaluation information
for the proposed Isolation Forest-based MITM anomaly detection
system.

## Expected Outputs

The proposed system is expected to produce:

1. Anomaly scores for ICS observations.
2. Identification of abnormal observations.
3. Detection results for MITM-related anomalies.
4. Comparison results between Isolation Forest and the selected
   baseline method.
5. Performance evaluation using the selected metrics.

## Expected Detection Output

The Isolation Forest model is expected to identify observations
that differ from normal ICS communication behaviour.

A higher anomaly score will indicate that an observation is more
likely to be anomalous.

## Evaluation Metrics

The proposed model will be evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- False Positive Rate (FPR)
- Detection Latency

## Note

The results in this folder represent expected or sample outputs
at the research proposal stage. They are not final experimental
results.
