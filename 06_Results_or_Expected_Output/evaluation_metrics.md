# Evaluation Metrics

The proposed Isolation Forest model will be evaluated using the
following metrics:

| Metric | Purpose |
|---|---|
| Accuracy | Measures the overall correctness of the detection results. |
| Precision | Measures how many observations identified as anomalies are actually anomalous. |
| Recall | Measures how many actual anomalous observations are successfully detected. |
| F1-score | Provides a balance between precision and recall. |
| False Positive Rate (FPR) | Measures normal observations that are incorrectly classified as anomalies. |
| Detection Latency | Measures the time required to identify an anomaly. |

The same evaluation metrics will be used when comparing Isolation
Forest with the selected baseline method.
