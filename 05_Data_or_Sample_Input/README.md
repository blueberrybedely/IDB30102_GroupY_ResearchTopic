# Data / Sample Input

This folder contains the proposed dataset information and sample
input for the MITM attack detection research.

## Proposed Dataset

The proposed research will use the Hardware-in-the-Loop Water
Distribution Testbed (WDT) dataset.

The dataset contains network and physical data representing normal
system behaviour and different attack scenarios, including
Man-in-the-Middle (MITM) attacks.

The WDT dataset was used in a previous study to evaluate anomaly
detection for different cyberattacks in a Cyber-Physical System
environment (Vaughn et al., 2024).

## Intended Use

The dataset will be used for:

- Data exploration
- Data preprocessing
- Feature selection
- Isolation Forest model development
- MITM anomaly detection
- Model evaluation

## Sample Input

The `sample_input.csv` file is provided to demonstrate the expected
input format of the proposed system.

The sample should contain selected network or system features that
can be analysed by the Isolation Forest model.

## Dataset Source

Dataset: Hardware-in-the-Loop Water Distribution Testbed (WDT)

Note: The complete dataset is not included in this repository.
Only a sample or dataset information is provided.
