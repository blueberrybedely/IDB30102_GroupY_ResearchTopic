# Detecting Man-in-the-Middle (MITM) Attacks in Industrial Control System (ICS) Networks Using Isolation Forest

## Project Overview

This research project focuses on detecting Man-in-the-Middle (MITM) attacks in Industrial Control System (ICS) networks using the Isolation Forest machine learning algorithm.

The project aims to identify abnormal network behaviour associated with MITM attacks and evaluate the effectiveness of Isolation Forest for attack detection.

## Research Aim

To develop and evaluate an Isolation Forest-based anomaly detection approach for detecting Man-in-the-Middle attacks in Industrial Control System (ICS) networks.

## Research Objectives

1. To identify the characteristics of Man-in-the-Middle attacks in Industrial Control System (ICS) network data.

2. To develop an Isolation Forest-based anomaly detection model for detecting Man-in-the-Middle attacks in ICS networks.

3. To evaluate the performance of the Isolation Forest model in detecting Man-in-the-Middle attacks using appropriate evaluation metrics.

## Scope of Study

This research focuses on detecting Man-in-the-Middle attacks in Industrial Control System networks using the Isolation Forest algorithm. The study will use a publicly available ICS network dataset containing normal and attack-related network traffic.

The study will involve data preprocessing and feature preparation before applying the Isolation Forest algorithm. The model will then be evaluated using appropriate performance metrics such as accuracy, precision, recall and F1-score.

## Significance of Study

This research provides an evaluation of the Isolation Forest algorithm for detecting Man-in-the-Middle attacks in ICS networks. The findings may contribute to research on machine learning-based anomaly detection and Industrial Control System cybersecurity.

## Dataset

The research will use the ICS-NAD dataset, a publicly available dataset containing network traffic from Industrial Control Systems. The dataset includes normal traffic and multiple types of cyberattacks, including Man-in-the-Middle (MitM) attacks.
